# Будущий S3: контракт, без подключения

SDK, credentials, bucket и сеть сейчас не подключены; `boto3` не добавлен. Параметры endpoint/bucket/region и политика — EXTERNAL. Логическая структура ключей внутри согласованного private bucket:

```text
nazar-109/
  releases/<source>/<release-id>/
  manifests/<source>/<dataset-id>.json
  backups/<source>/<release-id>/<UTC-date>/
  reports/<source>/<release-id>/
```

До решения по ПДн допускаются только FAKE, проверенные агрегатные отчёты без ПДн и отдельно признанные безопасными backups. REAL raw не включается автоматически. REAL data release/predictions/model backup не считается безопасным только из-за расширения файла; разрешение, состав, шифрование и доступ должны быть утверждены отдельно.

Требования при подключении: private bucket, отсутствие public ACL/policy, шифрование при передаче и хранении, versioning, минимальные права на согласованные prefixes. Разделить writer, reader и backup/restore роль; обычному writer не давать удаление всей истории. Credentials — secret store, не env-файл в git и не Docker image. После предоставления параметров проверить фактические ACL/policy/TLS/encryption/versioning и отрицательные проверки доступа; сейчас их состояние неизвестно.

Upload — immutable keys с manifest/checksums, проверка перед признанием backup готовым; не имитировать локальный atomic rename серией S3 PUT. Локальный CURRENT переключается только после полного restore/проверки на локальном томе. Retention/lifecycle, key rotation, audit access, ограничения хранения и юридическое основание требуют владельца данных. S3 не становится источником raw или scheduler-ом сам по себе.
