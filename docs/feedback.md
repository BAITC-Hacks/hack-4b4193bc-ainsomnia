# Feedback после аутентификации

Запись сейчас не реализована. Без проверенного actor нельзя обеспечить аудит; анонимный переключатель «подтверждено» не создаётся. Зависимость — [OIDC и роли](auth.md).

| Поле | Контракт |
|---|---|
| event_id | stable_id показанного Action Item; обязательна проверка принадлежности scope |
| created_at | Серверное время UTC, ISO 8601 |
| actor_id | Проверенный внутренний псевдоним из identity; клиент не выбирает |
| label | confirmed_event / seasonal / data_issue / no_action / needs_review / other |
| note_category | Закрытый справочник: evidence_checked / calendar_context / export_gap / duplicate_review / insufficient_evidence / other |

Свободного текста, ФИО, адресов и текста граждан нет. `other` не открывает поле произвольного комментария. Dataset/source/version и request_id сохраняются как серверная метаинформация записи, чтобы исторический feedback не переносился на другую выгрузку. Изменение ответа — новое событие с указанием предыдущего, без перезаписи истории аудита; политика retention ещё должна быть согласована.

Будущий writer: analyst, scope, проверка enum и существования события, идемпотентный request_id, транзакционная запись и audit outcome. Viewer не пишет, admin не получает право feedback автоматически. Feedback не становится ground truth и не запускает обучение без отдельной постановки качества разметки.

Приёмка: отказ без identity/вне региона/при неизвестной метке; actor нельзя подменить; повтор запроса не дублируется; ошибка хранилища не показывает успех; ПДн не принимаются ни в поле, ни в журнал. Сейчас это проект контракта, не работающий endpoint.
